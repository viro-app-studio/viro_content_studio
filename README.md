# کانتنت استودیو (Content Studio)

**استودیوی تولید محتوای فارسی با هوش مصنوعی** — دستیارهای اختصاصی، خدمات آماده‌ی نگارش، جست‌وجوی زنده‌ی ترندها و بررسی خودکار صحت، همه در یک برنامه‌ی سبک دسکتاپ.

## ✨ امکانات

- **دستیارهای اختصاصی:** دستیار با دستورالعمل و مدل دلخواه بسازید، در گروه‌ها مرتبشان کنید و با هرکدام گفت‌وگوی جداگانه داشته باشید (پاسخ زنده و استریم‌شده).
- **خدمات آماده:**
  - نگارش و بازنویسی پست شبکه‌های اجتماعی
  - تولید عنوان جذاب و قلاب ذهنی (Hook)
  - بهینه‌ساز سئو و استخراج کلمات کلیدی
  - مترجم تخصصی متن و مقاله‌ی علمی
- **بهینه‌ساز پرامپت:** پرامپت خام را به دستورالعمل دقیق و حرفه‌ای تبدیل کنید.
- **جست‌وجوی زنده:** ترندهای ۲۴ ساعت، ۳ روز یا ۷ روز اخیر از Google News فارسی و انگلیسی، Google Trends ایران و آمریکا، Bing، Reddit، Exa و خوراک‌های RSS دلخواه؛ با گسترش هوشمند کلیدواژه و رتبه‌بندی بر اساس ارتباط، تازگی، تنوع منابع و میزان تعامل.
- **بررسی خودکار صحت:** بعد از هر خروجی، ادعاها استخراج و با منابع سنجیده می‌شوند (درست / نادرست / نامشخص) و اصلاح با یک کلیک انجام می‌شود. از تنظیمات قابل خاموش‌کردن است.
- **Duck.ai:** متن را با یک کلیک به Duck.ai ببرید.
- **۱۶ تم روشن و تیره**، اندازه‌ی قلم قابل تنظیم و طراحی واکنش‌گرا برای دسکتاپ و موبایل.
- **پشتیبان‌گیری:** خروجی و ورودی JSON (ادغام یا جایگزینی کامل؛ پشتیبان‌های نسخه‌ی ۱ هم پشتیبانی می‌شوند).

## 🔒 حریم خصوصی

- همه‌ی داده‌ها (دستیارها، گفت‌وگوها، تنظیمات) **فقط روی دستگاه خودتان** ذخیره می‌شوند؛ هیچ سرور اجباری‌ای در کار نیست.
- **کلید API شما متعلق به شماست:** هر کاربر کلید سرویس دلخواهش را در تنظیمات وارد می‌کند و کلید از دستگاهش خارج نمی‌شود، جز برای ارسال مستقیم درخواست به همان سرویس.

## 🤖 سرویس‌های هوش مصنوعی پشتیبانی‌شده

| سرویس | توضیح |
|---|---|
| OpenRouter | دسترسی به ده‌ها مدل؛ گزینه‌ی «فقط مدل‌های رایگان» به‌طور پیش‌فرض روشن است |
| Google Gemini | از طریق Gemini API |
| OpenAI | مدل‌های GPT |
| OmniRoute / سرور سفارشی | هر API سازگار با OpenAI با آدرس دلخواه |

## 📥 دانلود و نصب (ویندوز)

از بخش [Releases](../../releases) یکی از دو فایل را دریافت کنید:

| فایل | کاربرد |
|---|---|
| `ContentStudio-2.2.0-setup.exe` | نصب‌کننده (حدود ۳ مگابایت)؛ در صورت نیاز WebView2 را خودش نصب می‌کند |
| `ContentStudio-2.2.0-portable.exe` | نسخه‌ی قابل‌حمل بدون نصب (حدود ۶ مگابایت)؛ نیازمند WebView2 که روی ویندوز ۱۰ و ۱۱ از پیش نصب است |

## 🚀 شروع سریع

1. برنامه را اجرا کنید و لایسنس خود را فعال کنید (یا از دوره‌ی آزمایشی استفاده کنید).
2. از دکمه‌ی چرخ‌دنده به **تنظیمات** بروید و کلید API یکی از سرویس‌ها را وارد کنید.
3. مدل را انتخاب کنید و از تب‌های **دستیارها**، **خدمات**، **بهینه‌ساز** یا **جست‌وجوی زنده** شروع کنید.

## 🔑 لایسنس

- فعال‌سازی از صفحه‌ی ورود برنامه یا **تنظیمات ← لایسنس و حمایت** انجام می‌شود.
- هر کلید به تعداد مشخصی دستگاه اجازه می‌دهد؛ برای انتقال به دستگاه دیگر، ابتدا همین دستگاه را از تنظیمات غیرفعال کنید.
- بعد از فعال‌سازی، برنامه تا مدتی بدون اینترنت هم کار می‌کند و هر از گاهی لایسنس را تمدید می‌کند.

## 🛠 توسعه

پیش‌نیازها: Node.js ۲۰ یا بالاتر، و برای نسخه‌ی دسکتاپ Rust و [پیش‌نیازهای Tauri 2](https://v2.tauri.app/start/prerequisites/).

</div>

```bash
npm install
npm run dev            # نسخه‌ی وب در مرورگر (بدون صفحه‌ی لایسنس)
npm test               # تست‌ها (Vitest)
npm run lint           # ESLint
npm run build          # بررسی تایپ و ساخت نسخه‌ی وب
npm run tauri dev      # اجرای نسخه‌ی دسکتاپ
npm run tauri build    # ساخت نصب‌کننده‌ی ویندوز
```

<div dir="rtl">

قبل از ساخت نسخه‌ی جدید، شماره‌ی نسخه را در `package.json`، `src-tauri/tauri.conf.json` و `src-tauri/Cargo.toml` به‌روز کنید.

```text

```

## English summary

**Content Studio** is a Persian (RTL) AI content studio for Windows: custom assistants with streaming chat, ready-made writing services (social posts, hooks, SEO, academic translation), a prompt optimizer, live multi-source trend search (Google News/Trends, Bing, Reddit, Exa, RSS) and automatic fact-checking with one-click fixes. Local-first: all data stays on the device, and each user brings their own API key (OpenRouter, Gemini, OpenAI or any OpenAI-compatible endpoint). Built with React 19, Vite and Tauri 2; the installer is about 3 MB.
